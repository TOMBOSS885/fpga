# 模型与推理配置

目前用户尚未部署模型，本包没有声明一个已经验证的模型。以下信息应在实际部署后填写，并同步到 `manifest.json`、运行环境和设计报告。

| 项目 | 当前状态 |
| --- | --- |
| 开源模型仓库 URL | 待填写 |
| 权重 revision / 文件 SHA-256 | 待填写，不能只用可变的 `main` |
| API served model ID | 通过 `LLM_MODEL` 配置 |
| 量化格式与具体权重版本 | 待填写；不得假定所有量化均支持目标 Radeon 架构 |
| 微调 | 本包未执行微调；使用微调权重时须补充基座、方法、数据与公开地址 |
| GPU 型号 / gfx / ROCm 版本 | 待实测 |
| 推理后端与版本 | 待填写；协议适配 vLLM/SGLang/llama.cpp/Ollama 的兼容接口 |
| 单卡显存峰值 | 待实测；健康检查的当前占用不能替代此项 |
| 服务端上下文长度 | 当前客户端默认 16384；必须改成实际后端配置 |
| agent 最大输出 | 默认 4096；短自测生成不超过 3072 |
| baseline 最大输出 | 官方固定 8192，不修改 |
| RoPE / chat template / reasoning 配置 | 待填写，agent 与 baseline 使用同一后端设置 |

同一解题批次不得按 `agent`/`baseline` 模式切换模型、量化、权重或上下文配置。为兼容官方基线元数据，所选模型应是 `/v1/models` 的第一个 ID，建议专用单模型实例。

实际权重、推理后端及 GPU 驱动不在本包中。正式提交前必须在单张不超过比赛显存预算的 AMD 卡上测试真实工作负载，记录冷启动、服务就绪、峰值显存、连续请求及断网运行结果。本文件没有提供虚构的显存或比赛分数。
